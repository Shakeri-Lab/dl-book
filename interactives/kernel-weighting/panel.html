Transcript and keyboard help
  1. Keep keys 1, 3, 5 and their observed values 1.5, 2.8, 1.8 fixed. At q = 3.5, the distances are 2.5, 0.5, 1.5.
  2. With bandwidth h = 0.6, the Gaussian affinities are approximately 0.00017, 0.70665, 0.04394. Divide each by their common sum, approximately 0.75076.
  3. The normalized weights are approximately 0.0002, 0.9413, 0.0585. Multiply each by its observed value and add: the prediction is approximately 2.7412. Calculations use unrounded weights.
  4. Now move the query across the same observations. A closer key generally gains influence relative to farther keys. Weights still sum to one; the prediction stays between 1.5 and 2.8. Return to q = 3.5, the printed witness.
