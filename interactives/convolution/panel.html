Read the walkthrough
  1. Place. Start with the top-left 3 × 3 patch. Each row is (0, 0, 1). The input is blue; the hand-chosen kernel is neutral.
  2. Multiply. The rays trace the top-right pixel of the patch and the top-right kernel weight into a multiplication point: 1 × 1 = 1. Its outgoing ray reaches the top-right product. Apply the same rule at all nine matching positions. The three product rows are (0, 0, 1), (0, 0, 2), and (0, 0, 1).
  3. Sum. Nine rays bring all nine products, including zeros, to one addition point. Their sum is 1 + 2 + 1 = 4. The outgoing green ray writes that value into the top-left output cell.
  4. Slide. Move right, then down, then left. These visits fill the other three output cells. The weights never change. Each valid patch crosses the same vertical edge, so every sum is 4.
