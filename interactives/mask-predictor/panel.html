Does the predictor at the last prompt slot contribute to the response score?

Word labels are illustrative aliases for the audit's unchanged token IDs, not tokenizer decoding. Read each input above its next target; ×0 or ×1 selects that target's score.

\( S_b=\sum_{i=0}^{5}\class{mp-mask}{m_{b,i+1}}\class{mp-logp}{\predictionpart{\log p_{b,i}(\targetpart{z_{b,i+1}})}} \)

Inputs stay available as context. Target masks select which log-probabilities enter the sum.

The mask and score receipt are readable without playback. Opening this panel loads the optional controls.

Here \(p_{b,i}\) is the model's next-token distribution given the entire prefix through slot \(i\), not just the word above it.

Scope and caveats

The supplied target at \(i+1\) selects a log-probability; its mask multiplies that score. The final padding input has no next target, so the aligned rows show six predictors and six shifted targets, including the padding target with ×0. This audit changes excluded output logits, not prompt input tokens, model parameters, or attention visibility. Changing the prompt could change the response probabilities. The helper returns a sequence sum of log probabilities; the SFT loss above negates and averages over scored response tokens. “Changed” is symbolic: no numerical probability or sequence score is claimed.
