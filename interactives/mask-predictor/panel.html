Watch the mechanism: which predictor does the mask exclude?

Does the predictor at the last prompt slot contribute to the response score?

Word labels are illustrative aliases for the audit's unchanged token IDs, not tokenizer decoding. Every token wears its role, prompt or response; watch where the roles end up when the targets are built.

\( S_b=\sum_{i=0}^{5}\class{mp-mask}{m_{b,\class{mp-next}{i+1}}}\class{mp-logp}{\predictionpart{\log p_{b,i}(\targetpart{z_{b,\class{mp-next}{i+1}}})}} \)

Inputs stay available as context. Target masks select which log-probabilities enter the sum.

The mask and score receipt are readable without playback. Opening this panel loads the optional controls.

Here \(p_{b,i}\) is the model's next-token distribution given the entire prefix through slot \(i\), not just the word above it.

Scope and caveats

The supplied target at \(i+1\) selects a log-probability; its mask multiplies that score. The final padding input has no next target, so the aligned rows show six predictors and six shifted targets, including the padding target with ×0. This audit changes excluded output logits, not prompt input tokens, model parameters, or attention visibility. Changing the prompt could change the response probabilities. The helper returns a sequence sum of log probabilities; the SFT loss above negates and averages over scored response tokens. “Changed” is symbolic: no numerical probability or sequence score is claimed. The travelling copy and its one-slot slide are a drawing device for the helper's token_ids[:, 1:] and response_mask[:, 1:]: no tensor moves at run time, the role tags are the mask row spelt in words, and on a narrow screen each three-slot strip is a window on the same tape, so the copy that leaves the second strip by its left end is the one that enters the first strip on the right.

Check yourself. Suppose the response began at slot 1, so that slot 0 held the only prompt token. Would slot 0's prediction be scored?

Yes. Its target is the token at slot 1, the first response token, and the mask rides on the target: slid one slot left, that target lands under slot 0 with ×1. A scored predictor always sits one slot before its response target, so here the first one is at slot 0. Only a slot whose own next token is prompt or padding is excluded.

Transcript and keyboard help
  1. Read sequence A using illustrative word aliases for the fixed IDs: prompt “Explain : why”, response “birds can fly”. Sequence B uses prompt “Explain :” and response “how planes also fly”. Each token card carries its own role tag, and each slot feeds one output. A marker rests under “why”, the last prompt slot. Predict whether that slot's output should count.
  2. The targets are built in front of you. A copy of every token card, role tag attached, drops below the outputs; then the whole copy slides one slot to the left. “Explain” falls off the left end, the final “[PAD]” enters on the right, and “birds”, still tagged response, comes to rest under slot 2, whose input “why” is tagged prompt. The picture then holds still; nothing is gated yet.
  3. Now the copies become the supplied targets. Each target's gate is read from the role tag that travelled with it: response gives ×1, prompt and padding give ×0. Row A scores targets “birds”, “can” and “fly” under slots 2, 3 and 4. The marker leaves “why”, takes slot 2's output along the side path to the gate of “birds”, passes ×1 and lands on the score rail. A predictor at slot \(i\) uses the whole prefix through that slot, not only the word above it.
  4. Sequence B's response starts one slot earlier. Its copy makes the same one-slot slide, so “how”, tagged response, stops under slot 1: four targets are scored, under slots 1, 2, 3 and 4. The marker restarts at prompt slot 0, whose next target “:” is still a prompt token.
  5. Hold sequence B fixed. Only outputs whose next targets have mask zero change, shown symbolically as “changed”. Both token sequences and all included terms stay fixed. A target's upward arrow selects its log-probability; the side path carries that score to the gate. An open gate's path runs on into the score rail; a closed gate's path ends at a stop bar.
  6. The marker carrying slot 0's changed output stops at its ×0 gate and empties: each changed term is multiplied by zero. The audit prints zero change in either sequence score.
  7. Revisit the boundary on sequence A: the marker runs from the last prompt predictor through the ×1 gate into the score, because the first response target has mask one.
  8. The prompt remains context. Masking target loss does not remove input tokens or block attention.
