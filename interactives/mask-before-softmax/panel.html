Watch the mechanism: zero is not a padding mask

Does giving padding a score of zero exclude it?

This expands the existing seeded audit, not a new sample or a trained alignment. The formula uses the scores currently shown. Setting padded scores to zero is deliberately wrong; negative infinity excludes them before normalization. This is source-padding masking, not target-loss or causal masking: all real source keys remain available. Bars share a ruler within each level, but exponentials and weights have different units. An all-masked row is rejected, never treated as four valid zero weights.

  2. Try the wrong repair: overwrite both padded scores with zero. Leave the real-key scores unchanged.
  3. Exponentiate each shown score. Each padded slot contributes one because exp(0) is one.
  4. Divide every contribution by the same sum. Padding receives about 0.5372 of the total weight, even though those source positions do not exist.
  5. Now replace padded scores with negative infinity before softmax.
  6. Both padded exponential contributions become zero and disappear from the shared denominator.
  7. The first two weights become 0.4090 and 0.5910; both padded weights are exactly zero. The complete row sums to one.
  8. The guard remains essential: at least one key must be valid. With no valid key, stop before normalization rather than returning an all-zero distribution.
