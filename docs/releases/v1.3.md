# Deep Learning: Making It Learnable v1.3

Version 1.3 is the course-arc and publication-contract release.

- Five new Part pages make the book's compounding argument visible between units:
  each transition identifies what was fixed, what becomes learnable, what structure
  is built in, and which failure motivates the next Part.
- Part III is now **Sequences: Learning the Summary** and Part V is now **The
  Pretrained Era: Learning What to Reuse**. The canonical HTML, route table,
  sidebar, PDF openers, printed contents, and outline use the same titles.
- The independent Preface, five-part route, canonical-edition statement, web
  identity, accessible interactions, cover-led free-PDF page, and deterministic
  stable-edition stamp are now one audited front door.
- Appendix E, the three interlude namespaces, book-wide Plan → Code interaction,
  expanded exercise bank, temperature arc, epilogue namespace and sources, and the
  July–August editorial and visual passes are included in this fixed edition.
- Both derived PDFs use uniform 0.85-inch margins. The facing-page print edition is
  548 pages; the one-sided continuous-screen edition is 519 pages.
- All 390 PDF outline entries land on the page containing their rendered heading.
  The five part bookmarks are retargeted to the new openers rather than duplicated.
- All 133 frozen stdout blocks remain byte-identical. Source, HTML, public-anchor,
  cross-reference, glyph, text-layer, geometry, accessibility, and PDF-outline
  audits pass on the release commit.

The HTML edition is canonical. Both attached PDFs are free derived conversions of
the same manuscript.
