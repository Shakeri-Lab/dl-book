# Lecture-link fallbacks

Phase D maps each of the book's 30 non-Part manuscript pages to the most specific
public DS 6050 lecture resource available. Twenty-seven pages have a chapter-specific
video, slide deck, or course segment. The three pages below use the complete lecture
playlist because no single lecture is an honest match:

- `index.qmd` — the Preface spans the complete course.
- `chapters/epilogue.qmd` — the Epilogue synthesizes the complete five-part arc.
- `chapters/appendices/a4-notation.qmd` — the notation appendix is a cross-book
  reference sheet rather than a lecture topic.
