# Public anchor contract

These URLs are public interfaces consumed by
[*Deep Learning: Making It Trainable*](https://shakeri-lab.github.io/opt-book/).
They may gain redirects, but they must not disappear or change target without a
coordinated update in both repositories. CI checks each source identifier and, after
rendering, the corresponding HTML fragment.
