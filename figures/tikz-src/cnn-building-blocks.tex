% Chapter "Modern CNNs and Transfer Learning", opening figure (fig-cnn-building-blocks).
% One row per architecture the chapter trains; columns compose a block, repeat it,
% add a head. Every box is a layer of the chapter's own code: atom and VGGSmall,
% nin_block and NINSmall, Block and DeepNet (the experiments stack twenty blocks).
% Colour grammar: every operator is neutral ink. A heavy outline marks what the row
% adds; the identity route runs forward into the sum (a 1x1 convolution only when a block changes
% the channel count or resolution; the chapter's Block keeps both, so its shortcut is a pure identity). Orange is reserved for
% learnable parameters and is not used here (author-gated: set learnable/.style below
% to {text=dlorange} to tint the conv, BN, and linear labels).
